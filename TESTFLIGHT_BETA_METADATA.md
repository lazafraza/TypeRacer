# TestFlight Beta Metadata (Ready to Paste)

## What to Test

1. Open TypeRacer from iMessage app drawer in a group chat.
2. Start a race and tap Send so others can join from the message bubble.
3. Verify live progress updates while multiple players type.
4. Finish race and verify winner/results card logic.
5. Try rematch and verify state resets correctly.

## Beta Description

TypeRacer is an iMessage typing game where friends race to complete the same quote. This beta focuses on race creation, multiplayer sync, WPM scoring, and result sharing.
